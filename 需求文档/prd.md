# 📄 PRD: “人生时间账单” (Life Time Bill)

> **2026-08-27 验收口径修订**：结果总览必须覆盖“当前年龄 → 预期寿命”的完整剩余人生；工作账单展示退休前被工作占用的完整在岗跨度，真正自由时间包含退休后自由时间，所有占比统一以完整剩余人生为分母。

## 1. 文档概述

* **产品名称**：人生时间账单 (Life Time Bill)
* **产品定位**：极简暗黑风、高视觉张力的纯前端打工人全生命周期工时换算与时间可视化工具。
* **技术架构**：纯前端单页架构（HTML5 + Tailwind CSS CDN + 原生 JavaScript / ES6 模块）。
* **核心依赖库**：
* 节假日与调休数据：通过 CDN 引入 `chinese-days` / `chinese-workday` 客户端解析库（内置官方发布的各年份放假与调休补班明细，无需额外后端网络接口）。
* 视觉与动效：Tailwind CSS (CDN)、CountUp.js、html2canvas。


* **核心目标**：通过精确的中国调休工时模型，将打工日常换算为多粒度的人生时间账单，支持海报生成与社交分享。

## 4. 节假日计算与调休处理模型

1. **客户端数据引擎（CDN 库接入）**：
* 页面引入本地打包或 CDN 版 `chinese-days` 离线数据集。
* 数据集包含历年及当年国务院公布的完整日历属性：`isWorkday`（是否工作日）、`isHoliday`（是否放假日）、`isWorkWeekend`（是否调休补班周末）。


2. **全年净放假工作日换算机制**：
* **标准模式 (`STANDARD`)**：

$$\text{年节假日净减工时} = \text{放假总天数} - \text{占用常规周末天数} + \text{周末调休补班天数}$$



*（直接基于 CDN 库统计全年因法定节假日实际少上的工作日天数，如基准净减少 11~13 个工作日）。*
* **自定义模式 (`CUSTOM`)**：
* 界面展示 7 大法定节日卡片，每张卡片明确标示：**“官方标准放 X 天（含调休）”**。
* 用户可单独增减各节日的实际放假天数，引擎自动根据用户输入的放假总天数与补班逻辑折算全年净减工作日。

## 5. 核心功能与交互流程

### 5.1 全屏 Hero 区域 (100dvh)

* **背景呈现**：`100dvh` 自适应视频背景（HTML5 `<video autoplay muted loop playsinline>`），覆盖深色半透明渐变遮罩。
* **快速预设（Presets）**：
* `大厂 996` (25岁 / 65退 / 早10晚10 / 单休 / 0天年假)
* `大小休打工人` (25岁 / 65退 / 早10晚8 / 大小休 / 5天年假)
* `体制内/外企 WLB` (25岁 / 60退 / 早9晚5 / 双休 / 10天年假)
* `自由职业/无休` (25岁 / 55退 / 早9晚9 / 无休 / 0天假)



### 5.2 实时响应与动效（Reactive Calculation）

* **即时计算**：表单任意字段变动（`input`/`change` 事件），所有输出看板实时触发重算，无须手动点击“提交”或“计算”按钮。
* **数字跳动动效**：核心大字变动时通过 CountUp.js 触发平滑递增/递减动画。

### 5.3 结果文案展示规范

结果看板必须醒目呈现以下两大主句（文案结构严格固定）：

1. **工作账单文案**：
> “到您 **`{retireAge}`** 岁退休，您一共要工作 **`{workDurationText}`**”


2. **自由账单文案**：
> “到您 **`{retireAge}`** 岁退休，属于您真正自由支配的时间是 **`{freeDurationText}`**”



### 5.4 三种粒度并列展示规则

结果区并列展示（或 Tab 切换）以下三种格式，确保数据全维度透视：

* **粒度 A（完整大单位）**：`X 年 X 月 X 天 X 小时`
* **粒度 B（中单位）**：`X 月 X 天 X 小时`
* **粒度 C（天与小时）**：`X 天 X 小时`（附纯小时总计展示：`共 X 小时`）

## 6. 社交分享与持久化规范

1. **URL 参数双向绑定**：
* 页面初始化时解析 `window.location.search` 并还原表单状态。
* 表单数据更新时调用 `history.replaceState` 实时同步 Query 参数，便于用户复制链接分享给他人直接查看相同配置。


2. **海报生成（Image Export）**：
* 点击“生成人生账单卡片”时，纯前端调用 `html2canvas` 将结果看板渲染为 9:16 移动端海报图并自动触发浏览器下载。

## 7. 验收标准 (Acceptance Criteria)

* [ ] **纯前端零网络依赖**：依托 CDN 引入的离线节假日库完成节假日与调休判定，无任何后端服务或外部 API 跨域依赖，断网也能正常运行。
* [ ] **严密调休算法**：正确处理调休补班（如国庆放 7 天、补班 2 天、实际净减 3 个工作日），大小休与年假扣减无逻辑冲突或负数溢出。
* [ ] **响应式与多端适配**：Hero 区域在移动端与桌面端均实现 `100dvh` 精准自适应（无滚动抖动与底部白边），表单与卡片在不同屏幕尺寸下均能自适应折行。
